4 · Несоответствия диапазонов

  • 84000–84460 (36 записей) — реальный конфликт. Книга делит этот интервал: 84000–84320 → через Куркамыс, 84330–84460 → через Локоть. Единая запись на сайте направляет всё через Локоть, то есть часть 84000–84320 планируется вопреки книге. Каждую запись нужно разделить на две.

6 · Руководство пользователя

Полная инструкция по работе с расширением — от установки до ежедневной работы.

6.1 · Установка (один раз на каждом компьютере)

  1. Распакуйте enakl-book3-tekshiruvchi.zip в постоянную папку, например C:\enakl-tekshiruvchi\. Папку нельзя удалять — Chrome читает расширение из неё.
  2. Откройте в Chrome страницу chrome://extensions и включите Режим разработчика (Developer mode, переключатель справа вверху).
  3. Нажмите Загрузить распакованное (Load unpacked) и укажите папку из шага 1.
  4. Откройте в e-nakl список маршрутов (ListPlanExport) — строки раскрасятся автоматически, слева внизу появится панель. Работает и в Edge (edge://extensions).

Если Chrome при запуске спрашивает про расширения в режиме разработчика — нажмите «Оставить». Это обычное предупреждение.

6.2 · Панель: перемещение и сворачивание

  • Перетаскивание: схватите панель за заголовок «⠿ Проверка по Книге 3» и перетащите в любое место экрана — например, если она закрывает переключение страниц. Позиция запоминается и восстанавливается после перезагрузки.
  • Сворачивание: кнопка «—» в заголовке сворачивает панель в круглую кнопку К3. На кнопке красным показывается число ошибок на текущей странице. Клик по кнопке разворачивает панель обратно. Кнопку тоже можно перетаскивать.

6.3 · Цвета строк

  • Зелёный — соответствует основной таблице книги; можно подтверждать.
  • Фиолетовый ◆ — дополнительный план: маршрут идёт по Примечанию к строке книги (например, ферганский коридор через Локоть). Если в примечании есть промежуточные пункты, которых нет на сайте — это указывается в строке.
  • Бирюзовый ◉ — согласованное отклонение: вы сами пометили это расхождение как согласованное (см. 6.5).
  • Жёлтый △ — цепочка верна, но диапазон оформлен не по разбивке книги.
  • Красный ✗ — противоречит книге или грубая ошибка ввода; причина написана в строке.
  • Серый · — чисто внутренний маршрут, правило Книги 3 не требуется.
  • Метка «НОВАЯ» — запись появилась после последней полной сверки (см. кнопку «Прогресс»).

6.4 · Кнопки панели

  • ✓ Подтвердить соответствующие — нажимает штатные кнопки подтверждения сайта для всех зелёных строк текущей страницы. Спрашивает подтверждение, между запросами делает паузу. Совет: выставьте «Показать 100 записей» — за раз подтвердится до 100 строк.
  • ⬇ Ошибки в Excel (все страницы) — загружает через штатный API сайта все записи (~9 800), проверяет каждую и скачивает CSV-файл со всеми проблемными строками. Файл открывается в Excel двойным кликом; колонки: ID, статус, узел, диапазоны, пункты на сайте, цепочка по книге, причина. Удобно для отчёта руководству или планирования исправлений.
  • 📊 Прогресс — показывает, сколько записей подтверждено из общего числа, с разбивкой по узлам (Ташкентский: …/482 и т.д.), и сколько новых записей появилось с прошлой сверки. Одновременно обновляет базу «известных» записей для метки «НОВАЯ».
  • Только проблемные — скрывает зелёные строки; повторное нажатие возвращает всё.

6.5 · Согласованные отклонения

Если расхождение с книгой — это сознательное решение (оперативный приказ, телеграмма), нажмите в красной строке ссылку «согласовать отклонение» и укажите основание (номер приказа). Строка станет бирюзовой и перестанет считаться ошибкой — причём для всех записей с тем же правилом книги и той же цепочкой. Ссылка «отменить» в бирюзовой строке возвращает всё обратно. Список хранится в браузере этого компьютера; в выгрузке CSV такие строки идут со статусом «Согласовано».

6.6 · Подсказка на странице редактирования

При открытии записи на редактирование (кнопка ✎) справа появляется панель «Книга 3: подсказка»: она читает заполненную форму и таблицу пунктов и показывает цепочку, которую требует книга, — по каждому пункту: «есть», «ДОБАВИТЬ (№ …)» или «убрать лишние». Панель обновляется на лету по мере изменения формы, её тоже можно перетаскивать и сворачивать. Автозаполнение формы сознательно не делается: форма сайта загружает справочники по частям, и «тихая» автоподстановка рисковала бы незаметно исказить данные — вместо этого панель даёт точный список действий, а сохраняете вы сами.

6.7 · Обновление при новой редакции книги

Когда выйдет новая редакция Книги 3, база правил пересобирается конвертором из файла книги (~10 минут), и в папке расширения заменяется один файл — rules_data.js, после чего на странице chrome://extensions нажимается ⟳ (обновить). Больше ничего менять не нужно.

6.8 · Устранение неполадок

  • Строки не раскрашиваются — обновите страницу (F5); проверьте, что расширение включено на chrome://extensions.
  • Панель пропала — вероятно, свёрнута: ищите круглую кнопку «К3» (её могли перетащить в любой угол).
  • CSV открылся «в одну колонку» — откройте файл двойным кликом из проводника (не через «Данные → Из текста»); разделители и кодировка уже настроены под русский Excel.
  • После обновления книги всё стало красным — заменён ли rules_data.js и нажат ли ⟳ на странице расширений?

7 · Насколько надёжны результаты?

  • Разбор книги и каждый вердикт прошли 5 независимых перекрёстных проверок: выборка правил 18/18, выборка вердиктов 59/59, попытка опровергнуть «соответствующие» записи 30/30 — всё подтверждено.
  • По каждому из четырёх крупных шаблонов выполнен поиск по всему тексту книги (49 таблиц, все примечания): документальных оснований для варианта с сайта не найдено (исключение — Фергана–Локоть, выделено отдельно).
  • JS-проверка расширения сверена построчно с Python-аудитом на живом сайте — расхождений нет.
Ограничения. Условные правила примечаний (порожние вагоны, скоропортящиеся грузы, «по заявкам грузоотправителей» и прочие указания Д-…) не являются безусловно обязательными — такие случаи помечаются жёлтым (предупреждение), окончательное решение принимает инженер. Инструмент ничего не меняет сам: подтверждение выполняется только штатной кнопкой сайта и только по вашей команде.

8 · Рекомендуемый порядок действий

  1. Начните с листов «Грубые ошибки» и «Проблемы диапазонов» Excel-отчёта — 49 записей, точные указания готовы.
  2. Согласуйте четыре шаблона с руководством: каждый — одно массовое решение (Куркамыс / Красное / Ивангород / Соловей). Если какой-то из вариантов введён сознательно (оперативное изменение маршрута) — оформите это документально.
  3. Подтверждайте зелёные строки расширением — 8 144 записи OK подтверждаются постранично одной кнопкой.
  4. Предложение владельцам сайта: простая валидация ввода (запрет обратных диапазонов, 6-значных кодов в полях диапазонов и дубликатов пунктов) полностью устранит класс грубых ошибок.
